USER GUIDE

Your memory, with the original in reach.

A local workspace for notes, people, projects and the things you want to follow through on.

1. Open your workspace

Run npm start in the project folder, keep the server running and visit http://localhost:4173. Create a private account, then choose your workspace name and timezone in Settings. A new workspace starts empty.

2. Save or import memory

In Memory, choose Add a memory. Keep the original wording and enter a date if you know it. Optionally connect the note to a contact or project.

Choose Import local memory to select Markdown or UTF-8 text from Codex or Claude. Preview the full text and duplicate status before saving. Large files become linked parts without truncation. Import copies the selected content; your original files remain unchanged. No external model is called during import.

3. Find and review what you saved

Search Memory to find matches across original source text and saved memory items. Filter by import source, person, project or topic. Open a result to read the full original and inspect its date, revision and import path.

Organizing a source suggests facts, preferences, decisions, goals, commitments and questions. Each suggestion keeps an exact quotation. Review it before choosing Keep this memory. You can dismiss a suggestion without deleting the original.

4. Ask your personal agent

Ask about saved preferences, promises or project updates. Answers include source citations you can open and check. Local retrieval works without a model connection. If you enable optional Gemini for an answer, your question and selected retrieved excerpts are sent to that provider after consent.

Suggested tasks wait for a separate confirmation. The agent does not contact people or send messages. Changed or forgotten sources invalidate dependent answers; ask again to use current content.

5. Keep useful context connected

Contacts group notes about a person. Projects group notes around work you want to complete. Tasks hold your own commitments and due dates. These records are optional; a note can stand on its own.

Supporting tools keep the earlier Overview, Notes & evidence, Follow-ups, Capture, Find people, This week and Activity views available. Reviewed evidence can suggest a follow-up; inspect its dated sources and current unknowns before acting.

6. Own the local library

Original notes live as readable .md files in the memory folder shown on the Memory page. A generated MEMORY.md lists the saved sources. The SQLite database retains search indexes, links, accounts, tasks, agent history and file synchronization state.

After editing an existing Markdown note, choose Refresh from files. Conflicting edits or missing files are shown for review. The app does not silently replace a conflicting original.

Back up both the memory folder and the database for full recovery. Settings offers a JSON export of core records, which is a portable copy rather than a complete system backup. Exports and backups contain private content and should remain private.

Forgetting a source removes its content from recall and withdraws dependent memories and answers. Existing tasks, exports and backups need separate review. No original Codex or Claude files are modified by import or source deletion.

Storage and privacy

By default the server listens on loopback, and the local computer holds your data. If you host Threadline elsewhere, that machine holds the files and database. Server operators can access stored data; use disk encryption and private backups.

Core storage, file import, browsing and search require no cloud service. External AI is optional and each request needs consent. Its provider charges and retention policies apply. API credentials stay on the server. Source content is reference material, including any instructions it contains.

When something needs attention

No search results: try a phrase from an original source, clear filters and confirm the source appears in Memory.

A Markdown file needs attention: restore or fix the file shown, then refresh. The app withholds stale content while a file is unavailable.

An answer needs refresh: its source changed or was forgotten. Ask again and inspect the current citations.

An edit conflicts: keep your unsaved text, refresh and inspect the latest revision before saving again.

Account recovery: the server operator can run npm run recover locally. There is no unauthenticated browser reset endpoint.
