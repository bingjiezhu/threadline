01 / START SMALL

Find the context behind one real task.

Start the application with npm start, open http://localhost:4173 and create your account. New accounts are empty; the separate npm run demo:warm command creates a fictional practice workspace.

  1. Save an authorized note with its real date and person.
  2. In Knowledge map, confirm an exact quote, topic and colleague's responsibility.
  3. In First week, define your goal, role and what done looks like.
  4. Prepare the plan. Read the source and unresolved questions.
  5. Approve only the steps you want. Real tasks appear in your workspace.
  6. Edit and save your introduction. Contact the colleague yourself; nothing is sent automatically.

Local source-backed mode needs no AI key. Optional AI sends selected authorized context only after consent; a missing key never produces a fake model result.

02 / WHEN CONTEXT CHANGES

The new owner should change the next step.

Capture the later source and explicitly replace the earlier route on the same topic and responsibility. Its event date must be later. Old plans become stale; prepare and review a new one. If sources conflict or no route exists, the app pauses instead of guessing.

Read a source, ask the right colleague, verify an outcome. None of those steps automatically grants access, certifies training or completes your goal.

03 / SLACK

Save a selected message, not an entire inbox.

The operator needs a protected HTTPS deployment, the included Slack manifest, a signing secret and an allowed team ID. An optional bot token enables a native confirmation modal. This release has not been installed in a real workspace.

  1. Configure both Slack interaction URLs to https://YOUR_HOST/hooks/slack and install the commands scope.
  2. In Threadline Chat & capture, issue a one-use linking code.
  3. In Slack, use /threadline link CODE.
  4. Choose Remember in Threadline on a message; confirm the source, person and permission in the modal or private web inbox.
  5. Use /threadline find TOPIC for a private lookup in your saved context.

The adapters do not automatically mirror upstream message edits/deletions or continuously read threads. See the bundled setup guide for signature checks and live acceptance.

04 / DISCORD

A user-installed memory shortcut.

Configure a Discord User Install application, its public key and application ID, then set the HTTPS interaction endpoint to /hooks/discord. Review the bundled commands and use npm run register:discord -- --apply only with operator approval and a bot token. The registration command affects your external application; it has not been run for you.

Link via /threadline link. Select Apps → Remember this on one message, then review it privately before permanent storage. Replies are ephemeral; normal user tokens and whole-inbox scanning are not used.

05 / CONTROL

Your records, with explicit boundaries.

Source and permission changes invalidate plans. Unfinished generated tasks are cancelled; stale derived text is cleared. Pending chat text is short-lived and separate from confirmed notes. Disconnecting a platform removes its pending inbox, not already saved notes.

Web export includes readable onboarding records. Core JSON restore restores ordinary contacts/projects/notes/tasks, not onboarding plan/route links or chat bindings. Use the documented full SQLite backup procedure to preserve the entire application. Keep backups and your server protected.

WeChat is manual copy/paste of selected text. iMessage, Workday API access, shared HR permissions, automatic outreach, billing and a managed public service are not shipped claims.
