THREADLINE / CAPTURE

A conversation worth keeping.

Select text on a web page, right-click, and choose Save in Threadline. You will confirm the person and context inside your workspace before anything is saved.

You stay in control.

This extension uses only the text you select. It does not read all pages, send messages, collect browsing history, or connect to personal WeChat.

The text is transferred in the new tab's URL fragment, which is not sent in an HTTP request. Threadline clears the fragment when Capture opens. The browser itself, other installed extensions, clipboard tools and the server operator are not outside your trust boundary.

A local workspace must be running on this device. A remote workspace requires HTTPS. Installation and real-browser compatibility should be checked on your target Chrome version.
