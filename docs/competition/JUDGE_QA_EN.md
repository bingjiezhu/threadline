# Direct answers — Clarity edition

**What does it do?** Helps a new employee find who to ask and what to do next, with a team note they can check.

**Why not search?** Compare against search and the real buddy process. The proposed value is preserving the note, person and next step together, and stopping guidance after confirmed context changes. Superiority is not measured yet.

**Where is AI?** An optional language-model adapter helps write a bounded plan. It was not called in this recording. The saved-note workflow is real; code and human confirmation control source, recipient and task creation.

**What does sandbox mean?** A safe test site for practice without changing the live application.

**Who enters the information?** Start with a few notes the employee is allowed to use. The workspace user confirms responsibility against the original words and date. There is no independent authority certification or automated company-wide data import.

**Who pays?** A manager is the proposed buyer. Test a real first-task pilot including preparation and correction time. No paying customer or validated price is claimed.

**What really runs?** Authenticated Node.js HTTP, SQLite, original notes, dated role records, plan validity checks, user-approved tasks, editable drafts and real progress records. It does not provision access, send a message or automatically finish the goal.

**What about Slack/Discord?** Signed selected-message adapters are implemented and tested using synthetic protocol requests. Real registration and account installation remain separate steps.

**Was all of this built at this event?** No. The Threadline foundation and subsequent layers are identified in the source package. The team must confirm exact event-window work and prior public availability. No commit dates are invented.
