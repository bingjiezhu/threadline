# Use Threadline without learning CRM terminology

Help new employees find who to ask and what to do next, using team notes they can check.

Run `npm start`, open localhost:4173, create your account and choose First task. Core records persist in SQLite.

1. Save an authorized team note and its actual date.
2. Confirm the relevant colleague and exact quotation in Knowledge map.
3. Set one goal and what a completed result looks like.
4. Find my next steps; read the original words and remaining questions.
5. Select steps, confirm and Add to my tasks. You send the editable message yourself.

Test site / sandbox = a safe practice site that does not change the live application. A source = the original note. An out-of-date plan = guidance that must be checked again before use. AI = optional model-written wording; it was not used in the recordings.

Use `npm run demo:clear` for separate fictional rehearsal. It does not change your normal database.

Read `public/guide-clarity.html` while the server is running, or the standalone HTML in deliverables. See OPERATIONS.md for complete SQLite backup and restore. Core JSON restore is not a complete reconstruction of every first-task link or connector binding.
