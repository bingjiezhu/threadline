# Adversarial review and resolved choices

These are explicit review perspectives, not separately executed model agents.

| Hard question | Decision / evidence |
|---|---|
| Is this still just another CRM? | First-week goal plus source/person/task states is the competition entry. Ordinary relationship workflows remain reusable infrastructure. |
| Does routing merely guess a colleague? | Explicit dated quotations, user-confirmed responsibilities and conflict/expiry checks; profile tags do not authorize anything. |
| Can a newer upload rewrite history? | Replacement requires a later event date and explicit same-topic/responsibility selection. |
| Is it agentic only in marketing? | A bounded workflow prepares, checks, pauses and creates selected actual tasks. Optional AI produces typed prose. The film labels local mode; live AI still needs a successful receipt. |
| Did approval actually create work? | Real SQLite tasks are linked to selected step IDs transactionally. Copy/send/result remain distinct. |
| Will the buyer pay? | Not known. Manager-sponsored first-task pilots must show value beyond handbook/search/buddy. Hiring cadence may favor cohort fees. |
| Are Slack/Discord really integrated? | Signature-verified runtime and setup/registration code exist. A real installation, client behavior and permissions are not yet tested. |
| Is private company knowledge being leaked into another chat? | Owner-bound account and private responses only, selected context only; no automatic cross-workspace sharing. Server operator still trusted. |
| What is the biggest remaining onboarding flaw? | A small explicit source map is still user-maintained. Its maintenance effort may erase the benefit; measure it before expanding. |
| Is existing code eligible? | Only organizers decide. Preserve the real baseline/diff and disclose new work and real timing. |
| Why no elaborate graph/agent infrastructure? | The bounded source/person/task dependency can be verified in a small database. Add infrastructure only after an observed limit. |
| Why not claim 100% safe or a guaranteed prize? | Neither tests nor a pitch establish that. Report actual scopes and accept external evaluation. |
