# Source review for an unmapped first task

This optional path reduces the manual annotation step; it is not an organization directory or a responsibility verifier. Saved-note planning and manual Knowledge map remain usable without an AI key.

1. Save the colleagues explicitly mentioned in your authorized team note. Keep the note's original date and words.
2. Create one open first-task goal. If it has no usable confirmed route, choose **Read a team note with AI**.
3. Select one dated note. Read the full displayed body. Sharing consent starts unchecked. Only that goal, selected note and IDs/names of allowed saved colleagues named in the note go to the selected provider; contact profiles/emails are not sent by this operation.
4. An unclear review displays questions without a confirm-person action. A candidate includes a unique exact quotation naming a known colleague and the provider/model. It remains unconfirmed. Check the meaning yourself: exact matching cannot prove that the colleague is responsible.
5. A separate unchecked confirmation establishes a guide through the existing quoted-route transaction. It creates zero tasks and grants no access. Existing confirmed context must be updated through **Update who to ask** instead of being silently replaced here.
6. Prepare a plan, then separately choose and approve the tasks. A guide is not an approver; availability, training and actual access remain to verify. Nothing is sent automatically.

The source-review job binds the selected goal/source versions, workspace generation and named-contact IDs/names/versions. Content, permission and source changes invalidate it and clear stored derived review results. Changes between inference and confirmation prevent confirmation. Deleting the source also invalidates the resulting plan and cancels unfinished derived tasks. A read or task completion is not a certified goal outcome.

Limitations:1–20 already saved allowed colleagues explicitly named in a note of at most12,000characters; full-name matching cannot resolve aliases; duplicate saved names require manual clarification. The server validates structure and quotation identity, not semantic truth or overall model accuracy. Provider errors remain visible without a person-guessing fallback. The complete operation is bounded to47seconds, with a45-second transport abort; a late response cannot continue to save a candidate. An explicit retry may incur another provider charge.
