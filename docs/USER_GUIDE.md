# Using Threadline

1. Start the local server and create an account.
2. In Memory, save a note or preview and confirm selected local files.
3. Search a keyword and open the original excerpt to check context.
4. Ask Personal agent about saved content and inspect its sources.
5. Link notes to people or projects, and confirm useful proposed tasks.

Supporting tools retain notes/evidence, follow-ups, capture, people search and weekly activity. Nothing is sent automatically.

Settings provides workspace export/restore. Memory and Personal agent ask for AI consent on each request. Keep local backups private; read OPERATIONS.md before restoring data.
