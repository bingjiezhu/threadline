# First week: a practical guide

Warm Start is a private workspace that helps you decide what to read, whom to ask and what to verify. It does not grant permissions, approve HR requests or certify employee performance.

## Start small

Create a contact for a real colleague. Capture only a note you are authorized to store. Supply the actual event date; unknown dates are allowed for ordinary notes but cannot establish a current knowledge route. In Knowledge map, choose the note, quote its exact wording, select the colleague and a concrete topic. Responsibility is guide, approver or mentor. You confirm the meaning; the software does not prove the colleague's authority from a matching quotation alone.

Create a first-week goal with the same topic and a testable definition of done. For example: “Run one approved sandbox test and explain its result to my buddy.” A goal is yours to edit, finish or reopen. Editing its substance invalidates older plans.

## Prepare, review, then act

Local mode builds a three-step proposal from a current route. Optional AI rewrites the plan using the approved context, only after consent. Both modes retain exact evidence and unresolved questions. Competing same-role owners pause; missing evidence produces no guessed colleague.

Review the proposed steps and choose which to add to Tasks. Explicitly approve them. Read the source yourself, edit and save the introduction draft, contact your colleague through your own channel, then mark actual progress. Copying text does not send it. Your security training and access are still unknown until verified outside this app. Complete the overall goal only after checking its actual outcome.

## When something changes

Save the newer source. In Knowledge map, confirm a new route and select which earlier route it replaces. Replacement must have a later event date, not simply a later upload. The source must support the same responsibility and topic. A newer source without explicit replacement may leave two competing routes, which correctly pauses planning.

Old plans are hidden after invalidation; unfinished generated tasks are cancelled and their derived prose is cleared. Independently created tasks are not automatically erased. A fresh plan is a new proposal, not permission to execute the previous one.

## Control your data

Withdraw a route in Knowledge map without deleting the note. Delete a source to remove its current content and invalidate dependent outputs. Source revisions replace the current body; the system does not archive all old note bodies. The operator and database backups remain trusted. Downloaded files are not remotely erased.

Web export contains readable onboarding sections. Core JSON import restores ordinary records, not these plan/route/binding relationships. For full recovery, use the documented SQLite backup procedure.

## Useful daily habit

Keep one real first-week goal open. Save only important context, not every message. When a colleague gives a correction, update the source and responsibility. Record the result after doing the work. This creates usable context without requiring a complete company directory.
